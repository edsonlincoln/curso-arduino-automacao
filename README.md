# 5 Projetos Arduino de Automação — E3Maker
Área do Aluno: **https://edsonlincoln.github.io/curso-arduino-automacao/**

Códigos, arquivos e vídeos das aulas do curso **5 Projetos Arduino de Automação — do primeiro LED à kitnet conectada**, por Lincoln Coutinho — E3Maker.

- `codigos/` — um projeto por aula, pronto para abrir na Arduino IDE (pasta com o mesmo nome do `.ino`).
- `docs/` — site da Área do Aluno (GitHub Pages).
- `qrcodes/` — QR code de cada aula, impresso na apostila.

Segurança: todas as práticas são em 5–12 V de corrente contínua.
