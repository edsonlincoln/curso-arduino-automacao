# 1.2 — Primeiro programa: pisca LED
**Objetivo:** fazer um LED piscar uma vez por segundo e entender `setup()` e `loop()`.

**Materiais:** Arduino UNO R3 (ou compatível), LED vermelho 5 mm, resistor 220 Ω, protoboard, jumpers.

| Pino do Arduino | Ligação |
|---|---|
| 13 | resistor 220 Ω → perna longa do LED |
| GND | perna curta do LED |
