# 2.1 — Lendo temperatura e umidade com o DHT22
**Objetivo:** Ler temperatura e umidade e mostrar no Monitor Serial.

**Materiais:** Arduino UNO, DHT22 (módulo de 3 pinos ou sensor solto + resistor 10 kΩ).

| Pino do Arduino | Ligação |
|---|---|
| 5V | VCC do DHT22 |
| 2 | dados do DHT22 |
| GND | GND do DHT22 |

⚠️ Só 5–12 V CC. GND comum entre a fonte e o Arduino quando houver MOSFET.

**Bibliotecas:** DHT sensor library (Adafruit) + Adafruit Unified Sensor
